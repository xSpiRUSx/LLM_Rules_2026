# Запросы и производительность

## Основные правила запросов

Перед написанием запроса проверить:

- точное имя объекта метаданных;
- точные имена реквизитов;
- точные имена табличных частей;
- точные имена измерений и ресурсов регистров;
- наличие похожего запроса в проекте.


## При написании запросов 1С, особенно динамически собираемых строк:

- Не использовать псевдонимы таблиц, совпадающие с именами полей, ресурсов или измерений регистра. Например, не давать алиас `Стоимость`, если в запросе есть ресурс `Стоимость`; использовать `СтоимостьТоваров`, `ОстаткиСебестоимости` и т.п.
- Если в запрос передается `ТаблицаЗначений` параметром, ее колонки должны быть типизированы через `ОписаниеТипов`. Нельзя передавать колонку со значениями типа `Произвольный`, если поле выбирается в запросе.
- Для ссылочной колонки `ТаблицаЗначений` передавать в конструктор `ОписаниеТипов` строку с полным именем типа напрямую:

  ```bsl
  ОписаниеТиповНоменклатуры = Новый ОписаниеТипов("СправочникСсылка.Номенклатура");
  ТаблицаНоменклатуры.Колонки.Добавить("Номенклатура", ОписаниеТиповНоменклатуры);
  ```

  Не оборачивать имя ссылочного типа в `Тип()`:

  ```bsl
  ОписаниеТиповНоменклатуры = Новый ОписаниеТипов(Тип("СправочникСсылка.Номенклатура"));
  ```

- Не использовать параметр-таблицу `&Таблица` напрямую в запросах с `ОБЪЕДИНИТЬ`, соединениями или сложной обработкой. Сначала поместить ее во временную таблицу:
  `ВЫБРАТЬ ... ПОМЕСТИТЬ ВТ_... ИЗ &Таблица КАК ...`,
  и дальше работать уже с `ВТ_...`.
- Проверять итоговую структуру запроса: временные таблицы, алиасы, `ОБЪЕДИНИТЬ ВСЕ`, секции `ВЫБРАТЬ/ИЗ/СГРУППИРОВАТЬ/ИМЕЮЩИЕ` и отсутствие неоднозначных имен.

## Формат запроса

Использовать переменную `Запрос` и отдельный текст запроса:

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	Контрагенты.Ссылка КАК Ссылка,
|	Контрагенты.ИНН КАК ИНН
|ИЗ
|	Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|	Контрагенты.ПометкаУдаления = ЛОЖЬ";

РезультатЗапроса = Запрос.Выполнить();
ТаблицаКонтрагентов = РезультатЗапроса.Выгрузить();
```

## Параметры

Запрещено подставлять значения в текст запроса конкатенацией.

Нужно:

```bsl
Запрос.УстановитьПараметр("Контрагент", Контрагент);
```

Нельзя:

```bsl
Запрос.Текст = "ВЫБРАТЬ ... ГДЕ Контрагент = " + Контрагент;
```

## Запросы в цикле

Запросы в цикле запрещены.

Нельзя:

```bsl
Для Каждого СтрокаТаблицы Из ТаблицаДанных Цикл

	Запрос = Новый Запрос;
	Запрос.Текст = "...";
	Запрос.УстановитьПараметр("Ссылка", СтрокаТаблицы.Ссылка);
	РезультатЗапроса = Запрос.Выполнить();

КонецЦикла;
```

Нужно:

- собрать массив ссылок;
- выполнить один запрос;
- построить соответствие результата;
- использовать соответствие в цикле.

## Временные таблицы

Для сложных массовых расчетов использовать временные таблицы.

Имена временных таблиц начинать с `ВТ_`.

```bsl
МенеджерВременныхТаблиц = Новый МенеджерВременныхТаблиц;

Запрос = Новый Запрос;
Запрос.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
Запрос.Текст =
"ВЫБРАТЬ
|	Данные.Номенклатура КАК Номенклатура,
|	Данные.Склад КАК Склад
|ПОМЕСТИТЬ ВТ_Данные
|ИЗ
|	&Данные КАК Данные";

Запрос.УстановитьПараметр("Данные", Данные);
Запрос.Выполнить();
```

## Виртуальные таблицы регистров

Фильтры по измерениям передавать в параметры виртуальной таблицы, если это возможно.

Предпочтительно:

```bsl
РегистрНакопления.ТоварыНаСкладах.Остатки(
	&Период,
	Склад = &Склад
)
```

Нежелательно:

```bsl
РегистрНакопления.ТоварыНаСкладах.Остатки(&Период) КАК Остатки
ГДЕ
	Остатки.Склад = &Склад
```

## Доступ к реквизитам ссылок

Не использовать массовый доступ через точку:

```bsl
ИНН = Контрагент.ИНН;
```

Предпочтительно:

```bsl
РеквизитыКонтрагента = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(
	Контрагент,
	"ИНН, КПП, Наименование");
```

Если БСП нет — использовать запрос.

## Типовые анти-паттерны

Критичные:

- запрос в цикле;
- доступ к реквизитам ссылок через точку в массовом коде;
- подзапрос в списке выбираемых полей, который выполняется для каждой строки;
- фильтр виртуальной таблицы в `ГДЕ` вместо параметров;
- множественные серверные вызовы из клиентского цикла.

Высокий риск:

- отсутствие `ПЕРВЫЕ N`, когда нужна ограниченная выборка;
- `&НаСервере` вместо `&НаСервереБезКонтекста`;
- отсутствие кеша для повторяющихся дорогих расчетов;
- вложенные циклы для поиска соответствий вместо `Соответствие`.
